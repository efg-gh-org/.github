# .github — efg-gh-org

Arquivos que o GitHub lê para a organização inteira: template de PR e de issue.

A regra da org (CLAUDE.md, hooks, skills) mora no repositório de configuração global,
não aqui (decisão de 23/09/2026, §12.2 da auditoria do GitHub).

Sem workflow de segurança por enquanto: o GitHub Actions está sem cota até 01/10/2026 e a
decisão foi economizar minutos; gitleaks e suíte rodam na máquina e vão colados no PR.
